# Contributing

**FANZi IO-nity** is proprietary, closed-source software owned by Ionity Global (Pty) Ltd.
The source code is not publicly available, so we are not accepting external code
contributions or pull requests to this repository at this time.

## How you can still help

- 🐛 **Report bugs** — open an [issue](../../issues/new/choose) with clear reproduction steps.
- 💡 **Suggest features** — open a [feature request](../../issues/new/choose).
- 📖 **Improve documentation** — suggestions for the [Wiki](../../wiki) are welcome via issues.

## Reporting Security Issues

Please see [SECURITY.md](SECURITY.md) for how to responsibly report security vulnerabilities.
