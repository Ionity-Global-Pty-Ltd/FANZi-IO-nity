# FAQ

**Q: Is FANZi IO-nity free to use?**
A: FANZi IO-nity is proprietary software published by Ionity Global (Pty) Ltd. See the
[LICENSE](https://github.com/Ionity-Global-Pty-Ltd/FANZi-IO-nity/blob/main/LICENSE) for
usage terms.

**Q: Is the source code available?**
A: No, FANZi IO-nity is closed-source. Only compiled releases are published.

**Q: Why does Windows SmartScreen warn me when I run the installer?**
A: This is common for independently published Windows applications that haven't yet
built up SmartScreen reputation. Choose **More info → Run anyway** if you trust the
source (official [Releases](https://github.com/Ionity-Global-Pty-Ltd/FANZi-IO-nity/releases) page).

**Q: Why does it need administrator rights?**
A: Direct hardware access (fan controllers, RGB controllers, low-level sensors)
requires elevated permissions on Windows.

**Q: Which hardware is supported?**
A: FANZi IO-nity targets common Windows motherboard fan headers, CPU/GPU sensors, and
popular RGB controllers. See [Troubleshooting](Troubleshooting) if a device isn't detected.

**Q: How do I report a bug or request a feature?**
A: Open an issue using the templates on the
[Issues](https://github.com/Ionity-Global-Pty-Ltd/FANZi-IO-nity/issues/new/choose) page.

**Q: How do I get help?**
A: See the [Support](Support) page.
