## 2. Search or open an issue

Most questions and bugs should go through GitHub Issues:

- [Search existing issues](https://github.com/Ionity-Global-Pty-Ltd/FANZi-IO-nity/issues)
- [Open a new issue](https://github.com/Ionity-Global-Pty-Ltd/FANZi-IO-nity/issues/new/choose)

## 3. Security issues

Do **not** open a public issue for security vulnerabilities. Instead follow the
process in [SECURITY.md](https://github.com/Ionity-Global-Pty-Ltd/FANZi-IO-nity/blob/main/SECURITY.md).
